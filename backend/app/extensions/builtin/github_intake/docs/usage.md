# Using the GitHub intake

1. Open **Profile → Import** and find the **GitHub** card.
2. Enter your GitHub login (not a URL) and choose **Preview**.
3. Tick the repositories you want. Each becomes a draft project; a
   repository with stars or forks also gets an achievement draft.
4. Choose **Create drafts**. Review them under your profile's draft
   experience list and activate what is accurate.

Repositories already present on your profile (matched by their GitHub URL)
are skipped, so running the intake twice is safe.
