# GitHub troubleshooting

**The preview is empty.** The profile has no public non-fork repositories,
or the login is wrong. Enter the login only (`octocat`), not the profile
URL.

**Rate limit reached.** GitHub limits anonymous API calls. Set an instance
token in **Settings → Tools → Connectors → MCP connectors**, or try again
later.

**A repository is missing.** Forks and private repositories are excluded by
design; only public, non-fork repositories are read.
