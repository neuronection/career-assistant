# Personio careers feed

Personio hosts the career sites of thousands of European employers under
`<tenant>.jobs.personio.de`. The public XML feed lists every open position
with its office, department, employment type, seniority and created date —
no account, key or token is needed.

Use this connector when the employer's careers page is a Personio site and
you want the roles to flow into the live postings feed. Personio's XML feed
carries no salary field, so salary stays empty unless the description
mentions one (the parser reads free-text salaries from the title).
