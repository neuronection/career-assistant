# Interview prep

Career Assistant can run **posting-grounded mock interviews**: practice that
is specific to the role you are applying for, with coached feedback and a
debrief you can act on.

Open the **Interviews** workspace (`/interviews`) from the sidebar, or start
one straight from a posting's detail page (the "Practice interview" button
creates, starts and jumps you into chat).

## Question plans

A session begins with a **question plan** calibrated to you:

- If the session is grounded in a posting, questions are built from the
  **deep posting extract** and your own skill levels for the required skills.
- Otherwise, they are built from a catalog archetype for the role.

You can edit the plan: reorder or remove questions. Questions you have already
answered are locked, so your history stays intact.

## Coached practice

Practice happens in the shared chatbot (the page hands off to the docked
chat — it never embeds a second transcript). Each answer is judged against a
three-part rubric:

- **Structure**
- **Evidence**
- **Clarity**

## Debrief

After the session, a debrief shows per-dimension aggregates so you can see
where you were strong and where you were thin. It also surfaces **learning
resources for your weak skills**, and a **one-click weak-area retry** starts a
new session focused on them.
